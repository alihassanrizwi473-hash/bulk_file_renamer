# Bulk File Renamer 📁
A Python-based file renaming tool that allows users to rename multiple files at once, saving time and simplifying file management.

## Project Overview
Bulk File Renamer is a Python-based automation tool designed to rename multiple files efficiently. It simplifies file management by allowing users to rename files in bulk instead of changing their names one by one.

## Features
- Rename multiple files at once.
- Automate repetitive file renaming tasks.
- Simplify file management.
- Save time by reducing manual work.

## Technologies Used
- Python
- OS Module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python bulk_file_renamer.py
```

## Project Purpose
This project was developed to practice Python automation, file handling, and working with the OS module.
